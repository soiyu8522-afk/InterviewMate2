# 면접메이트 (Swing 프로토타입)

목업 PDF 14장을 자바 Swing으로 옮긴 프로토타입입니다. 외부 라이브러리 없이 Java 8 이상만 있으면 실행됩니다.

## IntelliJ에서 실행 (카메라·마이크 포함)
1. IntelliJ `파일 > 열기` 에서 이 폴더의 **pom.xml** 을 고르고 **프로젝트로 열기** 를 누릅니다.
2. 오른쪽 위에 Maven 새로고침(🔄) 알림이 뜨면 누릅니다. (카메라 라이브러리를 자동으로 내려받아요)
3. `src/main/java/interviewmate/App.java` 의 `main` 옆 ▶ 버튼을 누릅니다.
4. 카메라가 안 나오면 Windows `설정 > 개인 정보 > 카메라` 에서 **데스크톱 앱이 카메라에 액세스하도록 허용** 을 켭니다.
5. 한글이 깨지면 `Settings > Editor > File Encodings` 를 UTF-8로 맞춥니다.

카메라까지 들어간 실행 파일을 만들려면: IntelliJ 오른쪽 Maven 창 → Lifecycle → **package** 더블클릭 → `target/InterviewMate-1.0.jar` 생성 (run.bat 이 이 파일을 먼저 실행합니다)

바로 실행만 해 보려면: Windows는 `run.bat` 더블클릭. (함께 들어 있는 InterviewMate.jar 에는 카메라 라이브러리가 없어서 카메라 대신 그림이 나오고, 마이크는 동작합니다)

## 화면 크기
- 실행하면 노트북 화면 높이에 맞춰 창 크기가 자동으로 정해집니다.
- **Ctrl +** 크게, **Ctrl -** 작게, **Ctrl 0** 화면에 맞춤 (면접 진행 중에는 바뀌지 않음)

## 파일 구성
| 파일 | 역할 |
|---|---|
| App.java | 실행 시작점, 화면 전환(뒤로가기 기록), 앱 상태(XP·포인트·퀘스트), 하단 탭바 |
| G.java | 색상·글꼴·둥근 사각형·아이콘 그리기 도우미 |
| Canvas.java | 직접 그리는 화면의 기본 클래스. `hit(x,y,w,h, 동작)` 으로 클릭 영역 등록 |
| Page.java | 고정 제목/버튼 + 가운데 스크롤 영역 화면의 뼈대 |
| Faces.java | 면접관 얼굴 일러스트 |
| Media.java | 카메라 화면 받기 + 마이크 소리 크기 계산 (실패하면 그림으로 대체) |
| CamGrabber.java | 웹캠 라이브러리(webcam-capture)를 쓰는 부분 |
| Data.java | 면접관 성향·질문·퀘스트·리포트 등 예시 데이터 |
| HomeScreen ~ ReviewScreen | 각 화면 (아래 표) |

| 목업 | 클래스 | 동작하는 것 |
|---|---|---|
| 홈 | HomeScreen | 퀘스트 진행도, 최근 면접 → 리포트, '더 많은 연습' 바로가기 |
| 면접관 선택 | SelectScreen | 성향·직무·문항 수 선택, 성향별 질문 예시 변경 |
| 피드백 방식 | FeedbackModeScreen | 실시간/녹화 후 선택, 체크박스 3개 |
| 면접 진행 | InterviewScreen | REC 타이머, 질문 넘기기, 실시간 피드백 칩, 마이크, 종료 |
| 돌발 상황 | InterviewScreen | 3번째 질문에서 등장, 30초 카운트다운, 다른 카드, 3:1 면접 전환, 빈도 조절 |
| 면접 리포트 | ReportScreen | 타임라인 점·Q탭 선택, 문항별 잘한 점/고칠 점, 퀘스트 보상 받기 |
| 데일리 퀘스트 | QuestScreen | 자정까지 남은 시간, XP 받기·레벨업 |
| 면접관 속마음 | ThoughtsScreen | 그래프 점/목록 선택 시 표정·말풍선 변경 |
| 주말 보스전 | BossScreen | 보상/친구 랭킹 탭, 도전 횟수 차감, 80% 넘으면 '깐깐한 임원형' 해금 |
| 채용공고 맞춤 | PostingScreen | 공고를 고치면 핵심 역량·빈틈·예상 질문이 즉시 다시 계산 |
| 자소서 피드백 | ResumeScreen | 3개 문항 탭, 형광펜 문장 클릭, '문장 바꾸기'로 점수 상승 |
| 예상 질문 | ExpectedScreen | 분류 필터, 답변 가이드 펼치기, 한 질문만 연습 |
| 기업 면접 정보 | CompanyScreen | 3개 탭, 100P로 후기 열기 |
| 후기 공유 | ReviewScreen | 입력칸, 단계 선택, 질문 추가/삭제, 받을 포인트 자동 계산 |

## 실제 기능이 아닌 부분 (예시 데이터)
- **실제로 동작**: 카메라 미리보기(설정 화면, 면접 중 '나' 화면, 리포트 마지막 장면), 마이크 소리 크기(말하는 중 표시, 침묵 시간, 목소리 크기, 말한 시간 비율로 '말 속도' 점수)
- **흉내만 냄**: 영상 녹화·재생, 음성 읽기(TTS), 시선 분석, 습관어("음…") 세기, AI 질문 생성
  점수와 피드백 문장은 `Data.makeSession()` 에서 만들어지니, 나중에 실제 AI 결과로 바꾸면 됩니다.
- 채용공고 분석은 `Data.KEYWORDS` 의 단어를 찾는 방식입니다.
